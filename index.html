Lesson Plans

Demo — data lives in this browser only. The three tabs below are views, not accounts: Setup is the admin side (grades, subjects, resources), Teacher is data entry, Principal is the summary view. In the real build, teachers get personal links that open only their assigned grade(s), the server rejects writes to another teacher's plan, and the principal's view is a separate roster-checked, read-only link — the demo can't enforce that, so all tabs are visible here.

Setup — grades, subjects, resources

Add grade levels, then per grade add subjects. Each subject gets its own resource inventory (books and workbooks) and teaching days — the teacher picks from that subject's inventory when planning.

Grade levels

How access works in the real build (not enforced in this demo)

Teachers get personal links that open only their assigned grade(s). The grade list comes from a Teachers roster, and the server rejects any write to a plan the teacher does not own. The principal's view is a separate, roster-checked, read-only link. This demo has no accounts, so every tab is visible here.

Teacher — plan the week

Write each day freehand. Pick the resource from this subject's inventory and add pages or chapters. The standards list below is your reference — check a standard when it has been taught and the date is stamped on it. When a subject's week is done, hit Add Week — it saves and checks that subject off in Subjects Entered.
