Lesson Plans

Demo — data lives in this browser only. The three tabs below are views, not accounts: Setup is the admin side (grades, subjects, resources), Teacher is data entry, Principal is the summary view. In the real build, teachers get personal links that open only their assigned grade(s), the server rejects writes to another teacher's plan, and the principal's view is a separate roster-checked, read-only link — the demo can't enforce that, so all tabs are visible here.

Setup — grades, subjects, resources

Add grade levels, then per grade add subjects. Each subject gets its own resource inventory (books and workbooks) and teaching days — the teacher picks from that subject's inventory when planning.

Grade levels

How access works

Teachers get personal links: ?view= shows one tab and ?grade= locks the grade dropdown to their grade, so a teacher link stays on that grade. The principal's view is a separate link. Server-side roster checks — the server rejecting a write to a plan the teacher does not own — are still future work, so these locks live in the page, not the server.

Teacher — plan the week

Write each day freehand. Pick the resource from this subject's inventory and add pages or chapters. The standards list below is your reference — check a standard for the week it is taught. The date lands inside that week, and teaching it again in a later week adds another date. When a subject's week is done, hit Add Week — it saves and checks that subject off in Subjects Entered.

Subjects Entered — week of

Click a subject to open it for editing. A check means you hit Add Week for that subject this week — it does not lock it.

Add Week saves this subject's week and checks it off above. Copy last week fills this subject's empty days from last week's plans — it never overwrites what you already wrote.
